O Servidor Administrativo

1- A função "Criar Documento"

Serve para criar documentos novos.
Um documento novo pode ser criado a partir de um modelo. Um modelo pode ser criado e armazenado com a função "Criar modelo de documento”.

2- A função "Criar modelo de documento”:

Esta função serve para criar um modelo de documento que será usado mais tarde.
Os modelos são armazenados no banco de dados e não podem ser retirados.
Um modelo deve ser claramente identificado.
Por exemplo, há um modelo de memorando com duas assinaturas; modelo de ata de reunião de colegiado; etc.

3- A função "Editar Rascunho”:

Esta função serve para editar um documento que ainda não foi terminado e encaminhado. Tais documentos são salvos como rascunhos.
Qualquer documento no estado de rascunho pode ser editado.
Uma vez que o documento é submetido como definitivo, não é mais possível editá-lo.

4- A função "Inlcuir novo destino (Oficio externo)”:

Esta função deve ser usada caso haja necessidade de se incluir um novo destino para um dado documento.

5- A função "Upload de anexos de documentos”:

Deve ser usada para fazer o upload de anexos de memorandos ou outros documentos.
O upload só é possível para anexos digitalizados e salvos em arquivos do tipo .jpeg, .gif ou .pdf. Os anexos de documentos submetidos devem ser salvos na base de dados.

6- A função "Vinclulação de UnBDoc”:

Permite associar o número de UnBDoc a um documento que será encaminhado para fora do MAT.
A vinculação de UnBDoc é uma arma poderosa para a localização de documentos e deve ser feita.

7- A função "Visualização de anexos de documentos”:

Permite visualizar os anexos de um determinado documento que já foi encaminhado.

8- A função "Visualizar documentos”:

Permite a visualização de um determinado documento que já foi encaminhado.
