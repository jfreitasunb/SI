\begin{abstract}

Se você tem conhecimentos em software livre que podem facilitar o trabalho de um administrador de rede na hora da migração do seu sitema proprietário e deseja compartilhá-los, a melhor forma de fazê-lo é ajudando à escrever o Guia Prático de Migração. Para tal, será necessário que você entenda um pouco de \LaTeX{}.

O \LaTeX{} é um sistema de processamento de textos muito usado para produzir artigos, resenhas, livros, documentos científicos e matemáticos de alta qualidade tipográfica que usa a linguagem \TeX{} como mecanismo de formatação.
Por ser uma ferramenta de diagramação muito poderosa e mundialmente conhecida, o ITI resolveu adotá-la como padrão para seus manuais. 

Este tutorial, feito com o \LaTeX{}, o ajudará a entender e dominar o básico desse padrão para que você possa contribuir com o Guia Prático, que também utiliza o \LaTeX{}. Ao terminar de ler este documento você estará apto a criar um manual estruturado em capítulos, seções e itens e a utilizar os vários tipos de formatação que esse sistema oferece. 

\end{abstract}

\chapter*{Uma breve introdução}
\addcontentsline{toc}{chapter}{Uma breve introdução}

A linguagem \TeX{} tem uma certa semelhança com a linguagem HTML embora a primeira precise ser compilada e a segunda não. Se você já criou páginas Web, vai entender o que eu estou falando. Nessa linguagem existem comandos que dizem ao compilador como um determinado texto deve ser formatado. Por exemplo, para enfatizar uma \emph{palavra} em \TeX\ usamos o comando \verb:\emph{palavra}:, enquanto, na linguagem HTML, usamos \verb:<strong>palavra<\strong>:.  

Da mesma forma, existem comandos para criar capítulos, seções e fórmulas matemáticas; para formatar parágrafos, alinhamentos e conteúdos. A partir daqui, vamos conhecer os comandos mais utilizados no nosso Guia Prático.

\chapter*{Criando um novo capítulo}
\addcontentsline{toc}{chapter}{Criando um novo capítulo}

Para criar um capítulo é muito simples. Basta colocar no seu arquivo .tex o comando \verb:\chapter{Nome do Capítulo}:. No entanto, capítulos declarados dessa forma são numerados, como nos livros. A intenção é que, no Guia Prático, os capítulos não sejam numerados. Para tal, deve-se usar o comando \verb:\chapter*{Nome do Capítulo}:. Mas, este comando faz com que o capítulo criado não seja colocado no sumário. Para resolver o problema usamos o comando \verb:\addcontentsline{toc}{chapter}{Nome do Capítulo}:. Como exemplo, o código para criação deste capítulo segue abaixo:
\begin{quote}
\begin{verbatim}
\chapter*{Criando um novo capítulo}
\addcontentsline{toc}{chapter}{Criando um novo capítulo}

Para criar um capítulo é...
\end{verbatim}
\end{quote}

\section*{Criando uma nova seção}
\addcontentsline{toc}{section}{Criando uma nova seção}

O procedimento para criar seções é idêntico ao anterior, apenas trocando \emph{chapter} por \emph{section}. Esta seção foi gerada com o código:
\begin{quote}
\begin{verbatim}
\section*{Criando uma nova seção}
\addcontentsline{toc}{section}{Criando uma nova seção}

O procedimento para criar seções...
\end{verbatim}
\end{quote}
