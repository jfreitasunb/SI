O módulo de "Gerenciador de Usuários"

1- A função "Adicionar Usuário"

Serve para adicionar um novo usuário ao sistema.
Todos os campos devem ser preenchidos corretamente .

Antes de cadastrar um usuário, certifique-se de que ele não está cadastrado.
Se já estiver cadastrado use a função “ modifica usuário”.


1-1 Dados Pessoais:


Preencher com nome e sobrenome.
O endereço deve estar correto com CEP válido.


No caso de visitante, deve-se colocar o endereço de origem (Se for professor visitante, colocar o endereço da instituição de origem).
O telefone residencial pode ser um telefone celular (não esquecer o DDD).


1-2 Endereço Eletrônico:


É importante preencher pelo menos um dos campos.


1-3 Documentos:


Em todos os casos, os números de matrícula, identidade, CPF e passaporte NÃO podem ser inventados!

Caso um professor ou um funcionário (recém contratado) do quadro ainda sem matrícula deseja ser cadastrado, ele deve ser cadastrado como VISITANTE.

O STATUS DE UM USUÁRIO SÓ PODE SER ALTERADO SE ELE TIVER A SUA NOVA MATRÍCULA.

No caso de "visitante" e/ou "estagiário" não há necessidade de CPF ou matrícula. Mas é necessário colocar um número de Identidade ou de passaporte para diferenciar dois usuários com mesmo nome.

1-4 Dados profissionais:


O preenchimento começa com o “status”.
A data de admissão é a data do cadastro.
O tipo contratual DEVE ser colocado. Caso o usuário seja visitante, não há necessidade de tipo contratual.
O nível é obrigatório no cadastro de professor do quadro, assim como a especialidade (ou área de atuação).
No caso de alunos de mestrado ou doutorado, deve-se especificar o tipo de bolsa, qual é a área e qual é o orientador.
Caso o aluno ainda não tenha orientador, colocar “indefinido” no campo “Professor Orientador”.


Uma vez digitadas as informações, checar para ver se há erros antes de clicar em “enviar dados”.
Uma vez enviados os dados, o usuário será cadastrado.

Em seguida, aparece uma tela solicitando um login (ou nome de usuário). O usuário define o seu login. O funcionário que efetua o cadastro não pode definir o login do usuário. A senha é atribuída automaticamente.
Não sair da tela com os dados da conta. Caso o arquivo em pdf contendo os dados da conta do usuário não possa ser impresso, o funcionário deve deixar o usuário anotar sua senha.

2- A função "modifica usuario ”:

Esta função serve para modificar/corrigir dados cadastrais do usuário.
Assim que o usuário for selecionado, os seus dados aparecem nos respectivos campos.

ATENÇÃO: O número de matrícula só pode ser alterado se o status e o tipo contratual também mudarem. Neste caso (e somente neste caso), deve-se preencher o campo “nova admissão”.

O campo “Data de encerramento” só pode ser alterada se o usuário precisar de mais tempo para continuar na sua função sem modificar o seu status. Por exemplo, é o caso de alunos de mestrado ou doutorado que precisam de mais tempo antes da defesa da tese.

Os campos “Nível”, “Professor Orientador”, “Bolsista”, “Especialidade” podem ser alterados independentemente dos outros campos.

O campo “Situação” deve ser atualizado nas seguintes situações:
1.o aluno usuário aluno defendeu sua tese;
2.o aluno usuário foi desligado abandonou;
3.o professor usuário foi redistribuído;
4.o professor usuário aposentou-se.

3- A função "Pesquisa de usuários”:

Serve para pesquisar dados de usuários.
Basta selecionar os dados desejados marcando as caixas correspondentes.
A pesquisa pode ser coletiva ou individual.
